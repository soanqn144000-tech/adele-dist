# 아델 설치 — 클로드 코드가 대신 한다

이 폴더는 **아델**이다. 텔레그램으로 말을 걸면 업무를 챙겨 주는 개인 비서다.
「클로드 코드 열기」가 이 파일을 여기 놓고 너를 켰다. 사람의 첫마디는 보통 "아델 깔아줘"다.

## 지금 말을 거는 사람

- **개발자가 아니다.** 쉬운 우리말로 말하고, 한 번에 하나만 묻는다.
- **명령어를 사람에게 치라고 하지 마라.** 네가 친다. 사람은 대답만 한다.
- 사람이 직접 해야 하는 일은 딱 셋이다: 텔레그램 열쇠 받아오기 · 인증번호 읽어주기 · 교회 암호 말하기.
- 막히면 **왜 막혔는지 말로** 설명한다. 조용히 넘어가지 마라.
  끝내 안 되면 "이 화면을 사진 찍어 아델을 알려 주신 분께 보내 주십시오" 라고 한다.

## 설치 도구

압축을 푼 아델 안에 설치 도구 `setup.py` 가 있다.

    맥      ~/Adele/프로그램/_internal/features/setup.py
    윈도우  %USERPROFILE%\Adele\_internal\features\setup.py

못 찾으면 이 폴더 아래에서 `setup.py` 를 찾아라. 먼저 `python3 setup.py 상태` 로 어디까지 됐는지 본다
(윈도우는 `python` 또는 `py`). 없는 단계만 한다. 도구는 아델을 **뒤에서 조용히 켜서** 쓴다 — 창을 띄울 필요 없다.

**파이썬이 없을 때** (맥에서 "개발자 도구를 설치하시겠습니까" 창이 뜨거나, 윈도우에서 스토어가 열림):
사람에게 파이썬을 깔라고 하지 마라. 대신 아델 서버에 직접 말을 건다.

1. 아델을 뒤에서 켠다 — 맥 `~/Adele/프로그램/Adele --serve &` · 윈도우 `Start-Process "$env:USERPROFILE\Adele\Adele.exe" --serve -WindowStyle Hidden`
2. `http://127.0.0.1:8471/api/hello` 가 답할 때까지 기다린다(8472·8473 일 수도 있다)
3. 아래 주소에 JSON 을 POST 한다 (setup.py 가 하는 일과 똑같다)

| 단계 | 주소 | 보내는 것 |
|---|---|---|
| 지금 설정 | `GET /api/config` | — |
| 이름·저장 | `/api/save` | `{"bot_name": "다니엘"}` 처럼 설정 몇 개 |
| 텔레그램 로그인 1 | `/api/save` 그다음 `/api/tg/code` | `{"tg_api_id","tg_api_hash","tg_phone"}` → `{"phone"}` |
| 텔레그램 로그인 2 | `/api/tg/signin` | `{"phone","code","password"}` (2단계 암호 없으면 빈 값) |
| 로그인 됐나 | `/api/tg/status` | `{}` |
| 봇 만들기 | `/api/bot/make` | `{"title": 비서이름}` → 받은 `token` 을 `/api/save` 에 `telegram_bot_token` 으로 |
| 교회 지식 풀기 | `/api/unlock` | `{"password": 교회암호}` |
| 방 목록 · 고르기 | `/api/rooms` | `{}` → 고른 것을 `/api/save` 에 `rooms: {"core":{이름:id}, "mixed":{…}}` |
| 24시간 켜두기 | `/api/alwayson` | `{}` |

`/api/remote/firebase`(파이어베이스)는 부르지 마라 — 막혀 있다.
| 점검 | `GET /api/brain` · `GET /api/guard` | — |

## 순서

1. **이름** — "비서를 뭐라고 부를까요?" (아래 보안 규칙의 이름 규칙을 지킨다)
2. **교회 암호** — "부장님께 받으신 교회 암호를 말씀해 주십시오." 모르면 부장님께 여쭈라고 한다.
   **암호를 파일·메모·답에 적어 두지 마라.** `암호` 명령에 넣기만 한다.
3. **텔레그램 열쇠** — 사람이 직접 받아와야 한다. 이렇게 안내한다:
   1. 인터넷 창에서 **my.telegram.org** 에 들어갑니다
   2. 전화번호를 +82 10… 꼴로 넣으면, 텔레그램 **앱으로** 확인 코드가 옵니다(문자 아님). 그걸 넣습니다
   3. **API development tools** 를 누릅니다
   4. App title 과 Short name 에 영어로 아무거나(예: `memo2468`), Platform 은 Desktop
   5. Create application → 나오는 **api_id(숫자)** 와 **api_hash(긴 영문)** 를 알려 주십시오
   - "ERROR" 가 뜨면 Short name 을 바꾸고, VPN·광고차단을 끄고 다시 해 봅니다
4. **전화번호 → 인증번호** — 텔레그램 앱으로 오는 번호를 불러 달라고 한다. 2단계 암호를 쓰는 분이면 그것도.
5. **봇 만들기** — 기다리라고 말하고 돌린다(1분쯤).
6. **방 고르기** — 방 목록을 번호로 보여주고, 매일 챙겨 볼 방을 고르게 한다.
7. **24시간 켜두기** — 이걸 켜야 텔레그램으로 말을 걸 수 있다.
8. **점검** — 진짜 되는지 돌려보고, 된 것만 됐다고 말한다.
9. 끝나면 이렇게 알려준다: "이제 텔레그램에서 비서 봇에게 말을 걸어 보십시오. 다음에 저를 부르실 때도 「클로드 코드 열기」를 누르시면 됩니다."

업무 레이더 화면을 인터넷(파이어베이스)에 올리는 것은 **보안 규정 때문에 막혀 있다.** 권하지 마라.
화면은 그 컴퓨터 안에서만 본다. 나머지 기능은 다 된다.

## 보안 규칙 — 정보통신부 텔레그램 봇 보안 지침

**봇은 텔레그램에서 검색된다. 모르는 사람이 말을 걸 수 있다고 전제한다.** 이 규칙은 사람이 원해도 느슨하게 하지 마라.

1. **봇 이름에 소속이 드러나는 말을 넣지 않는다.** 단체 이름·신앙 용어·내부 용어는 안 된다
   (설치 도구가 걸러낸다. 무엇이 걸렸는지 도구가 말해 준다). 평범한 이름을 권한다 — 보기: 다니엘 · 하루비서 · 메모도우미.
2. **주인은 로그인한 본인 텔레그램 계정 하나뿐이다.** 봇은 그 계정 말고는 누구에게도 대꾸하지 않고,
   단체방에 넣으면 스스로 나온다. "가족·동료도 쓰게 해 달라"고 하면 그렇게 못 한다고 말한다 —
   각자 자기 컴퓨터에 따로 깔아야 한다.
3. **비밀값을 드러내지 않는다.** 봇 토큰 · api_hash · 교회 암호 · 인증번호를 답에 되풀이하지 말고,
   파일에 따로 적지 말고, 인터넷(깃허브·메신저·AI 채팅)에 올리지 않는다. 설정은 아델이 제 폴더에 알아서 둔다.
   `config.json` 은 열어서 읽지 않는다(상태는 `setup.py 상태` 로 본다).
4. **주인이 이상하면** (남이 주인이 됐거나, 본인 말에 답이 없으면) `setup.py 주인다시` 를 돌린다.
5. 사람이 주민번호·연락처 같은 **남의 개인정보**를 AI 에 넣으려 하면 한 번 말린다.
6. 봇을 더 안 쓸 때는 @BotFather 에서 `/deletebot` 으로 지우고 정보통신부에 알리라고 안내한다.

설치를 마치면 사람에게 한 줄 알려준다:
"교회 규정상 봇을 만들면 **정보통신부에 신고**하고, 매달 보안 점검 결과를 내야 합니다 — 양식은 부장님께 받으십시오."

## 설치가 끝난 뒤

이 폴더(`~/Adele`)는 프로그램 자리다. 사람의 설정·기능 코드는 따로 있다:

    맥      ~/Library/Application Support/Adele
    윈도우  %LOCALAPPDATA%\Adele

기능을 고쳐 달라는 말이 나오면 거기서 한다(거기에도 안내 파일이 있다).
「클로드 코드 열기」를 다시 누르면 설치가 끝난 사람은 거기서 바로 열린다.
