# 아델 설치 — 클로드 코드가 대신 한다

이 폴더는 **아델**이다. 텔레그램으로 말을 걸면 업무를 챙겨 주는 개인 비서다.
「클로드 코드 열기」가 이 파일을 여기 놓고 너를 켰다. 사람의 첫마디는 보통 "아델 깔아줘"다.

## 0. 이 글을 인터넷 주소로 읽었다면 (아델 폴더 밖에서 켜진 클로드)

사람이 받는 화면(get.html)에서 "아델 깔아줘 + 이 글 주소"를 붙여넣었다는 뜻이다. 그 사람이 시킨 일이다.
먼저 아델 본체를 받아 놓는다 — 사람에게 시키지 말고 네가 돌린다(몇 분 걸린다고 먼저 말한다).

    맥      curl -fsSL https://raw.githubusercontent.com/soanqn144000-tech/adele-dist/main/start/start.sh | ADELE_START_PREPARE=1 bash
    윈도우(PowerShell)  $env:ADELE_START_PREPARE=1; $b=(New-Object Net.WebClient).DownloadData('https://raw.githubusercontent.com/soanqn144000-tech/adele-dist/main/start/start.ps1'); iex ([Text.Encoding]::UTF8.GetString($b))

끝에 `READY: <폴더>` 가 찍히면 됐다. 그 폴더의 `CLAUDE.md` 가 바로 이 글이다. 그다음은 아래 순서대로 이어서 한다
(setup.py 는 그 폴더 아래에 있다). 실패하면 찍힌 말을 그대로 사람에게 쉬운 말로 옮긴다.
바탕화면에 「클로드 코드 열기」 도 놓인다. 다 끝나면 "다음에 저를 부르실 때는 바탕화면의 「클로드 코드 열기」 를
두 번 누르시면 됩니다" 라고 알려준다.

## 지금 말을 거는 사람

- **개발자가 아니다.** 쉬운 우리말로 말하고, 한 번에 하나만 묻는다.
- **명령어를 사람에게 치라고 하지 마라.** 네가 친다. 사람은 대답만 한다.
- 사람이 직접 하는 일은 **대답뿐**이다: 비서 이름 · 교회 암호 · 전화번호 · 텔레그램 앱으로 온 번호(두 번) ·
  (일정을 붙이면) 앱 전용 암호. **사이트에 들어가 뭘 베껴 오라고 하지 마라** — 열쇠는 네가 받아 온다.
- 막히면 **왜 막혔는지 말로** 설명한다. 조용히 넘어가지 마라.
  끝내 안 되면 "이 화면을 사진 찍어 아델을 알려 주신 분께 보내 주십시오" 라고 한다.

## 설치 도구

설치 도구 `setup.py` 는 **아델 폴더 맨 위에 있는 것**을 쓴다 — 시작할 때 늘 최신으로 받아 둔다.

    맥      ~/Adele/setup.py
    윈도우  %USERPROFILE%\Adele\setup.py

없을 때만 실행파일 안의 옛것(`프로그램/_internal/features/setup.py`)을 쓴다 — 옛것에는 「열쇠」·「일정」 이 없다.
못 찾으면 이 폴더 아래에서 `setup.py` 를 찾아라. 먼저 `python3 setup.py 상태` 로 어디까지 됐는지 본다
(윈도우는 `python` 또는 `py`). 없는 단계만 한다. 도구는 아델을 **뒤에서 조용히 켜서** 쓴다 — 창을 띄울 필요 없다.

**파이썬이 없을 때** (맥에서 "개발자 도구를 설치하시겠습니까" 창이 뜨거나, 윈도우에서 스토어가 열림):
사람에게 파이썬을 깔라고 하지 마라. 대신 아델 서버에 직접 말을 건다.

1. 아델을 뒤에서 켠다 — 맥 `~/Adele/프로그램/Adele --serve &` · 윈도우 `Start-Process "$env:USERPROFILE\Adele\Adele.exe" --serve -WindowStyle Hidden`
2. `http://127.0.0.1:8471/api/hello` 가 답할 때까지 기다린다(8472·8473 일 수도 있다)
3. 아래 주소에 JSON 을 POST 한다 (setup.py 가 하는 일과 똑같다)

| 단계 | 주소 | 보내는 것 |
|---|---|---|
| 지금 설정 | `GET /api/config` | — |
| 이름·저장 | `/api/save` | `{"bot_name": "다니엘"}` 처럼 설정 몇 개 |
| 텔레그램 로그인 1 | `/api/save` 그다음 `/api/tg/code` | `{"tg_api_id","tg_api_hash","tg_phone"}` → `{"phone"}` |
| 텔레그램 로그인 2 | `/api/tg/signin` | `{"phone","code","password"}` (2단계 암호 없으면 빈 값) |
| 로그인 됐나 | `/api/tg/status` | `{}` |
| 봇 만들기 | `/api/bot/make` | `{"title": 비서이름}` → 받은 `token` 을 `/api/save` 에 `telegram_bot_token` 으로 |
| 교회 지식 풀기 | `/api/unlock` | `{"password": 교회암호}` |
| 방 목록 · 고르기 | `/api/rooms` | `{}` → 고른 것을 `/api/save` 에 `rooms: {"core":{이름:id}, "mixed":{…}}` |
| 24시간 켜두기 | `/api/alwayson` | `{}` |
| 일정 붙이기 | `/api/cal/check` | `{"kind":"icloud"또는"google","id","pw","name"}` → 되면 저절로 저장 |

**텔레그램 열쇠(파이썬 없이)** — setup.py 의 「열쇠」·「열쇠코드」 와 같은 일을 curl 로 한다(쿠키를 이어 쓴다):
1. `POST https://my.telegram.org/auth/send_password` 폼 `phone=+8210…` → `{"random_hash":…}`
2. 사람이 불러 준 코드로 `POST /auth/login` 폼 `phone, random_hash, password=<코드>` → `true` 이고 쿠키가 생긴다
3. `GET /apps` — `app_id` 옆 `<strong>숫자</strong>` 와 `app_hash` 옆 32자리를 읽는다.
   없으면 그 화면의 `name="hash"` 값으로 `POST /apps/create` 폼 `hash, app_title, app_shortname`(영문 소문자+숫자 아무거나),
   `app_url=, app_platform=desktop, app_desc=` 를 보내고 `/apps` 를 다시 읽는다.
4. 읽은 값을 화면에 찍지 말고 바로 `/api/save` 에 `tg_api_id, tg_api_hash, tg_phone` 으로 넣는다.

`/api/remote/firebase`(파이어베이스)는 부르지 마라 — 막혀 있다.
| 점검 | `GET /api/brain` · `GET /api/guard` | — |

## 순서

1. **이름** — "비서를 뭐라고 부를까요?" (아래 보안 규칙의 이름 규칙을 지킨다)
2. **교회 암호** — "부장님께 받으신 교회 암호를 말씀해 주십시오." 모르면 부장님께 여쭈라고 한다.
   **암호를 파일·메모·답에 적어 두지 마라.** `암호` 명령에 넣기만 한다.
3. **텔레그램 열쇠와 로그인** — 사이트에 보내지 말고 네가 받는다.
   1. "텔레그램에 쓰시는 전화번호를 알려 주십시오" → `setup.py 열쇠 <전화번호>`
   2. "텔레그램 앱의 「Telegram」 공식 대화방에 영문·숫자가 섞인 코드가 왔습니다. 불러 주십시오"
      → `setup.py 열쇠코드 <코드>` — 열쇠를 받아 넣고, **곧바로 로그인 번호를 한 번 더 보낸다**
   3. "이번엔 숫자 다섯 자리가 왔을 겁니다" → `setup.py 인증번호 <번호>` (2단계 암호를 쓰는 분이면 그것도)
   - 두 번 다 **문자가 아니라 텔레그램 앱으로** 온다고 미리 말해 준다. 첫 코드와 둘째 번호가 다르다는 것도.
   - 「열쇠코드」 가 끝내 못 받으면 그때만 my.telegram.org 에 직접 들어가는 길을 안내하고 `setup.py 텔레그램 <api_id> <api_hash> <전화번호>` 로 넣는다.
4. **봇 만들기** — 기다리라고 말하고 돌린다(1분쯤).
5. **방 고르기** — 방 목록을 번호로 보여주고, 매일 챙겨 볼 방을 고르게 한다.
6. **일정 (선택)** — "폰 달력의 일정도 비서가 챙기게 할까요?" 원하면:
   - "아이폰이세요, 갤럭시세요?" → `setup.py 일정 icloud` 또는 `일정 google` — 앱 암호 받는 곳을 열고 방법을 찍는다.
     그 방법을 한 단계씩 쉬운 말로 옮긴다(애플은 애플 ID 로그인, 구글은 2단계 인증이 켜져 있어야 한다).
   - 받은 암호와 아이디로 `setup.py 일정 icloud <애플ID> <앱암호>` → 달력이 여럿이면 하나를 고르게 해 다시 넣는다.
   - 싫다고 하면 넘어간다. 나중에 "일정 붙여줘" 하면 그때 한다.
7. **24시간 켜두기** — 이걸 켜야 텔레그램으로 말을 걸 수 있다.
8. **점검** — 진짜 되는지 돌려보고, 된 것만 됐다고 말한다.
9. 끝나면 이렇게 알려준다: "이제 텔레그램에서 비서 봇에게 말을 걸어 보십시오. 저를 다시 부르실 때는 바탕화면의 「클로드 코드 열기」, 비서가 골라 둔 할 일은 「업무 레이더 열기」 를 두 번 누르시면 됩니다."

**업무 레이더(자동감지)** — 비서가 텔레그램 방을 훑어 할 일을 골라 두는 화면이다. 사명자는 이것만 본다
(주간 운영표·상태별 같은 다른 판은 없다 — 2026-11-17 부장님 지시). 바탕화면의 「업무 레이더 열기」 를
두 번 누르면 이 컴퓨터 안에서 열린다. 끝날 때 이것을 한 번 알려 준다. 처음엔 방을 훑기 전이라 비어 있다.
인터넷(파이어베이스)에 올리는 것은 **보안 규정 때문에 막혀 있다.** 권하지 마라.

## 보안 규칙 — 정보통신부 텔레그램 봇 보안 지침

**봇은 텔레그램에서 검색된다. 모르는 사람이 말을 걸 수 있다고 전제한다.** 이 규칙은 사람이 원해도 느슨하게 하지 마라.

1. **봇 이름에 소속이 드러나는 말을 넣지 않는다.** 단체 이름·신앙 용어·내부 용어는 안 된다
   (설치 도구가 걸러낸다. 무엇이 걸렸는지 도구가 말해 준다). 평범한 이름을 권한다 — 보기: 다니엘 · 하루비서 · 메모도우미.
2. **주인은 로그인한 본인 텔레그램 계정 하나뿐이다.** 봇은 그 계정 말고는 누구에게도 대꾸하지 않고,
   단체방에 넣으면 스스로 나온다. "가족·동료도 쓰게 해 달라"고 하면 그렇게 못 한다고 말한다 —
   각자 자기 컴퓨터에 따로 깔아야 한다.
3. **비밀값을 드러내지 않는다.** 봇 토큰 · api_hash · 교회 암호 · 인증번호 · 앱 전용 암호를 답에 되풀이하지 말고,
   파일에 따로 적지 말고, 인터넷(깃허브·메신저·AI 채팅)에 올리지 않는다. 설정은 아델이 제 폴더에 알아서 둔다.
   `config.json` 은 열어서 읽지 않는다(상태는 `setup.py 상태` 로 본다).
4. **주인이 이상하면** (남이 주인이 됐거나, 본인 말에 답이 없으면) `setup.py 주인다시` 를 돌린다.
5. 사람이 주민번호·연락처 같은 **남의 개인정보**를 AI 에 넣으려 하면 한 번 말린다.
6. 봇을 더 안 쓸 때는 @BotFather 에서 `/deletebot` 으로 지우고 정보통신부에 알리라고 안내한다.

설치를 마치면 사람에게 한 줄 알려준다:
"교회 규정상 봇을 만들면 **정보통신부에 신고**하고, 매달 보안 점검 결과를 내야 합니다 — 양식은 부장님께 받으십시오."

## 설치가 끝난 뒤

이 폴더(`~/Adele`)는 프로그램 자리다. 사람의 설정·기능 코드는 따로 있다:

    맥      ~/Library/Application Support/Adele
    윈도우  %LOCALAPPDATA%\Adele

기능을 고쳐 달라는 말이 나오면 거기서 한다(거기에도 안내 파일이 있다).
「클로드 코드 열기」를 다시 누르면 설치가 끝난 사람은 거기서 바로 열린다.
